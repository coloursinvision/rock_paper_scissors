# Security policy

## Supported versions

Only the current state of the `main` branch is supported. The project
publishes no releases and no packages to an index, so fixes land on
`main`.

## Reporting a vulnerability

Report a vulnerability privately through GitHub's advisory form:
<https://github.com/coloursinvision/rock_paper_scissors/security/advisories/new>

Do not open a public issue for it. The first response comes within 30
days. A confirmed vulnerability is fixed on `main` and then disclosed in
a GitHub security advisory.

## Scope

In scope: the code in this repository, its CI workflow and its lock
files. Vulnerabilities in a conda-forge package or a GitHub Action
belong to that project's maintainers.
